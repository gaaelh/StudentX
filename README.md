# StudentX

## Project Description

StudentX is a social networking application designed for university students to connect, communicate, and participate in campus activities.

The application will allow students to create clubs, organize events, communicate through public and private chats, buy and sell used academic materials, share campus updates, and ask questions through a campus help system.

The main goal of StudentX is to improve communication, collaboration, and student engagement within the university community.

## Project Objectives

- Develop a social networking application for university students.
- Implement CRUD (Create, Read, Update, Delete) operations.
- Allow students to create and manage clubs and events.
- Provide public and private messaging.
- Create a marketplace for used academic materials.
- Allow students to share campus updates.
- Provide a campus help system.

## Main Features

- **Clubs:** Create and manage student clubs.
- **Events:** Create, view, edit, and delete campus events.
- **Campus Chat:** Communicate through general and private chats.
- **Marketplace:** Buy and sell used books, computers, and academic tools.
- **Social Feed:** Follow students and clubs and share updates.
- **Campus Help:** Ask questions and receive assistance.
- **User Management:** Register, log in, and manage user profiles.
